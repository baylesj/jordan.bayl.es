I'm a senior software engineer at Google on the Chrome Media team, working on Chrome's audio stack: the parsers
and pipelines that turn audio files and streams into sound. Lately I've focused on hardening that code by moving it
to Rust and fuzzing it, and on better debugging tools and docs.

Earlier work includes the backend for [tab region capture](https://developer.chrome.com/docs/web-platform/region-capture/),
a rewrite of Chrome's [Cast Streaming](https://support.google.com/chromecast/answer/3228332?hl=en&co=GENIE.Platform%3DDesktop)
implementation, and the [Open Screen library](https://github.com/baylesj/openscreen).

Most of my work is public in [Chromium code review](https://chromium-review.googlesource.com/q/owner:jophba@chromium.org).
